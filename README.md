# ImageChan

Приложение отправитель фото для второй программы: Отправляет второму приложению определённые фотографии с помощью локального подключения.
Инструкция для использования(после скачивания)

    1. Сначала откройте второе приложение на другом ПК. Потом узнайте автоматически созданный порт и IP от другого компьютера.
    2. Введите эти порт и IP в этом приложении и дождитесь подключении(при неверном подключении выведется ошибка).
    3. Потом появятся 10 кнопок, при нажатии которых у второго Пользователя появятся определённые картинки.
